# 순간 다시 듣기

카드에서 그 구간의 실제 음성을 듣는 기능이에요. 음성을 녹음하고, 올리고, 카드 구간만 잘라 두는 데까지는 [음성 저장](audio.md)에 있고, 여기는 그 음성을 카드에서 듣는 화면과 API예요.

- 음성은 카드 주인만 들어요. 보관함에서만 들을 수 있고, 다른 곳(공유한 만화 등)에는 음성이 나가지 않아요
- 재생 바는 듣는 위치를 옮기는 용도예요. 구간을 골라 카드를 다시 만드는 기능은 이번 범위가 아니에요
- 음성 저장을 끈 녹음의 카드에는 음성이 없어요

## 1. 카드의 음성 상태

카드마다 음성이 세 가지 상태 중 하나예요.

| 상태 | 언제 | 화면 |
| --- | --- | --- |
| `READY` | 카드 구간 음성이 서버에 있음 | 재생 버튼이 보여요 |
| `PENDING` | 음성 저장을 켠 녹음인데 음성이 아직 안 올라옴(녹음이 끝난 지 7일 안) | 안내 문구가 보여요 |
| `NONE` | 음성 저장을 끈 녹음, 또는 녹음이 끝난 지 7일이 지나도록 음성이 안 올라옴 | 음성에 대한 것을 아무것도 보여 주지 않아요 |

- `PENDING` 안내 문구: "음성이 아직 올라오지 않았어요. 올라오면 여기서 들을 수 있어요"
- `PENDING`은 모바일 데이터에서 "Wi-Fi에서 올리기"를 골랐거나 올리는 중일 때 생겨요. 카드가 먼저 생기고 음성은 나중에 붙어요([음성 저장](audio.md) 3장·4장)
- 음성이 늦게 붙었을 때 푸시는 보내지 않아요. 앱은 카드를 열 때 상태를 다시 봐요
- 폰에 남아 있던 음성이 올라가기 전에 지워지면(로그아웃 등) 그 카드는 음성이 끝내 붙지 않아요. 이런 카드도 녹음이 끝난 지 7일이 될 때까지는 `PENDING`으로 보이고, 그 뒤에 `NONE`이 돼요

## 2. 화면

화면을 어디에 둘지는 앱 담당과 정해요.

- 카드 자세히 화면에 재생·멈춤 버튼, 재생 바, 지난 시간과 전체 길이가 보여요. 재생 바를 끌면 듣는 위치가 옮겨져요
- 카드 화면을 나가거나 다른 앱으로 가면 재생이 멈춰요. 백그라운드에서는 재생하지 않아요
- 녹음 중에는 재생 버튼을 꺼 둬요. 스피커로 틀면 그 소리가 지금 녹음에 다시 들어가기 때문이에요
- 보관함 목록에서는 음성이 있는 카드(`READY`)에 작은 표시를 보여요

## 3. 듣는 방법

1. 앱이 카드 자세히(`GET /api/cards/{id}`)를 불러요. 응답의 `audio`에 상태가 들어 있어요
2. `READY`면 재생 버튼을 보여 줘요. 누르면 앱이 `audio.url`에서 파일을 통째로 받아 폰의 임시 폴더에 두고 재생해요
3. `PENDING`이면 안내 문구를 보여 줘요. 다음에 카드를 열 때 다시 확인해요
4. `NONE`이면 음성에 대한 것을 아무것도 보여 주지 않아요

- `audio.url`은 10분 동안 열리는 서명 주소예요. 만화 그림(`imageUrl`)과 같은 방식이에요
- 받아 둔 파일이 없고 주소가 오래됐으면 카드 자세히를 다시 불러 새 주소를 받아요
- 파일은 AAC(ADTS, `.aac`)예요. 안드로이드에 들어 있는 `MediaPlayer`로 재생해요(라이브러리를 더하지 않아요)
- 이 파일에는 전체 길이가 적혀 있지 않아요. 재생 바의 전체 길이는 응답의 `audio.durationMs`로 그려요
- 임시 폴더의 파일은 카드 화면을 나갈 때 앱이 지워요. 로그아웃·탈퇴 때도 지워요

## 4. API

새 주소는 없고, 카드 응답에 필드를 더해요. 필드 정의는 [API DTO](api-dto.md)의 CardDetail·CardSummary에도 있어요.

**카드 자세히** `GET /api/cards/{id}`의 CardDetail에 `audio`를 더해요.

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| audio.status | String | O | `READY`·`PENDING`·`NONE` |
| audio.url | String | null 가능 | `READY`일 때만. 10분 동안 열리는 서명 주소 |
| audio.durationMs | Long | null 가능 | `READY`일 때만. 음성 길이(밀리초). 카드 구간에 앞뒤 여유 0.5초씩이 더해진 길이예요 |

**카드 목록** `GET /api/cards`의 CardSummary에 `hasAudio`(Boolean)를 더해요. `READY`일 때만 true예요.

- 예전 앱은 모르는 필드를 무시해서 그대로 동작해요
- 음성 주소는 만화 그림과 같은 버킷으로 열려요. Nginx에서 그 경로는 이미 GET이 열려 있어요([배포 설정](deployment.md) 2장)
- 서버는 카드 구간 음성을 저장할 때 종류를 `audio/aac`로 적어 둬요
