# 쇼츠 효과음·배경음 (FR-EXT-03, 제안)

업데이트 설계_v4 2번 탭(음성·배경 공개 API)이에요. **정함**은 지원이 정한 것, **Claude가 정함**은 지원이 맡겨서 Claude가 정한 백엔드 설계예요. 워커와 맞닿는 곳(콘티 칸, 소리 목록 요청·응답)은 AI 담당 확인에 따라 바뀔 수 있어요.

## 1. 정한 것 (정함 11-14, 지원)

- 효과음·배경음은 Freesound에서 **CC0 소리만** 미리 모아 두고 써요. 쇼츠를 만들 때마다 외부 API를 부르지 않아요
- 라이선스는 CC0만 써요. 출처 표기 없이 쓸 수 있고, Freesound API 약관의 "임시 사본만" 규칙과도 부딪히지 않아요. LOLog는 누구나 APK를 받을 수 있지만 수익이 없는 비상업 프로젝트예요
- 소리는 **정해진 검색어 값 중에서 골라요**(AI 담당 제안 수용). 콘티 LLM이 검색어 목록에서 하나(`door_slam`, `bgm_comic` 같은 값)를 고르고, 그 검색어로 모은 소리 중 하나를 워커가 jobId로 뽑아요
  - 이유: 소리가 200~300개이고 검색어가 정해져 있으면, 정해진 값 중 고르기가 결과를 예측하기 쉽고 시험하기 쉬워요. 콘티 검사로 틀린 값을 바로 막을 수 있어요
  - 소리 묶음이 커져 검색어로 다 담을 수 없게 되면 그때 벡터 검색(`sound_library`에 벡터 열 더하기)을 다시 봐요
- 대사 목소리는 지금처럼 Jetson TTS 그대로예요. 공개 TTS API는 쓰지 않아요(대화가 외부 회사로 나가지 않게)

## 2. 흐름

1. **모으기(한 번):** 수집 스크립트가 Freesound에서 검색어마다 CC0 소리를 받아 api에 넣어요
2. **콘티:** 영상 콘티 장면마다 `sfx`(검색어 값, 없으면 null), 영상 하나에 `bgm`(검색어 값, 없으면 null)을 더해요. 고를 수 있는 값은 아래 검색어 목록뿐이에요(AI 담당, [영상 콘티](video.md#5-영상-콘티))
3. **고르기:** 워커가 `GET /internal/sounds?kind=SFX&query=door_slam`으로 그 검색어 소리 목록을 받아 jobId로 하나를 골라요
4. **섞기:** 워커가 소리를 받아 대사 wav 위에 numpy로 섞어(대사가 나오면 배경음을 줄이는 덕킹) wav 하나로 만들고, 지금처럼 `video_render.py`의 ffmpeg에 넘겨요. ffmpeg 명령은 그대로예요

- 대사·대화 내용은 오가지 않고 검색어 값만 api로 가요

## 3. 모을 양

- 검색어 목록은 아래로 확정이에요(정함 11-14, 민주. ai `src/lolog_ai/sounds.py`의 `SFX`·`BGM`, LOLog-ai #46). 콘티는 이 값만 고를 수 있어요

| 종류 | 검색어(뜻) |
| --- | --- |
| 효과음 24개 | `door_slam`(문 쾅), `footsteps`(발소리), `laugh`(여럿이 웃음), `applause`(박수), `phone_notify`(폰 알림·진동), `keyboard`(타자), `dishes`(식기·컵), `car_horn`(경적), `rain`(비), `wind`(바람), `dog`(개), `cat`(고양이), `pop`(뿅), `fail`(실패·허탈), `success`(짠), `rimshot`(바둠츠), `whoosh`(휙), `thud`(쿵), `sigh`(한숨), `gasp`(헉, 놀람), `ding`(띵, 깨달음), `cafe`(카페 웅성거림), `classroom`(교실 웅성거림), `crowd`(거리·행사장 소음) |
| 배경음 5개 | `bgm_upbeat`(신남), `bgm_calm`(잔잔), `bgm_tense`(긴장), `bgm_sad`(슬픔), `bgm_comic`(코믹) |

- 검색어마다 CC0 5~10개, 효과음 5초 이하·배경음 30~60초. 합쳐 200~300개, ogg로 100MB 아래
- 검색어 목록은 api와 ai 콘티 검사가 같은 값을 써야 해요. 목록을 바꿀 때는 둘 다 같이 바꿔요
- Freesound에는 쓸 만한 CC0 배경음악이 적을 수 있어요. 모아 보고 적으면 배경음 검색어를 줄여요

## 4. 나누는 범위

| 누구 | 할 일 |
| --- | --- |
| 지원(api) | 수집 스크립트(받기·넣기), `sound_library` 표, 소리 넣기·빼기·목록 `/internal`, MinIO 저장 |
| 민주(ai) | 콘티에 `sfx`·`bgm` 검색어 값 넣기(검사 포함), 워커에서 목록 부르기·고르기, numpy로 대사 wav에 섞기·덕킹 |

## 5. 백엔드 설계 (Claude가 정함 11-14, 지원이 맡김)

lolog-api develop의 패턴에 맞췄어요.

### DB (다음 Flyway 번호)

```sql
CREATE TABLE sound_library (
    id BIGINT NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    kind VARCHAR(5) NOT NULL,              -- SFX(효과음), BGM(배경음)
    query VARCHAR(30) NOT NULL,            -- 검색어 값(door_slam 등). 콘티가 고르는 값과 같음
    title VARCHAR(200),                    -- Freesound 제목
    object_key VARCHAR(255) NOT NULL,      -- defaults/sounds/{id}.ogg
    duration_ms INT NOT NULL,
    freesound_id BIGINT NOT NULL,          -- 같은 소리를 두 번 넣지 않게
    source_url VARCHAR(500) NOT NULL,      -- Freesound 페이지(출처 기록)
    license VARCHAR(10) NOT NULL DEFAULT 'CC0',
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT sound_library_pk PRIMARY KEY (id),
    CONSTRAINT uk_sound_library_freesound_id UNIQUE (freesound_id),
    CONSTRAINT ck_sound_library_kind CHECK (kind IN ('SFX', 'BGM')),
    CONSTRAINT ck_sound_library_license CHECK (license = 'CC0')
);
CREATE INDEX idx_sound_library_kind_query ON sound_library (kind ASC, query ASC);
```

- 사람마다의 데이터가 아니라서 탈퇴로 지우지 않아요

### 저장

- MinIO `lolog-comics` 버킷 `defaults/sounds/{id}.ogg`. 기본 화자 그림(`defaults/characters/`)과 같은 자리예요
- 워커는 목록 응답의 10분 서명 주소로 받아요. 서비스가 모아 둔 공용 파일이라 만화 그림·기본 화자 그림과 같은 방식이에요(사용자 원본은 api가 직접 주는 것과 나눔). 워커는 목록을 받자마자 쓰니 만료 걱정이 없어요

### /internal API (지금 /internal과 같은 인증)

| 메서드 | 주소 | 부르는 쪽 | 하는 일 | 본문 | 응답 |
| --- | --- | --- | --- | --- | --- |
| PUT | /internal/sounds/{freesoundId} | 수집 스크립트 | 소리 넣기·바꾸기(같은 freesoundId면 덮어씀) | multipart `file`(audio/ogg, 5MB 이하), `kind`, `query`, `title`, `durationMs`, `sourceUrl`, `license`(CC0만) | 200 `{ id }` |
| DELETE | /internal/sounds/{freesoundId} | 수집 스크립트 | 어울리지 않는 소리 빼기. 파일도 지움. 없어도 204 | - | 204 |
| GET | /internal/sounds?kind=SFX&query=door_slam | 워커(3호) | 그 검색어로 모은 소리 목록 | - | 200 `{ sounds: [ { id, kind, durationMs, url } ] }` |

- `query`: 검색어 값, 영어 소문자·숫자·`_`, 1~30자. `kind`: `SFX`·`BGM`
- 목록은 `id` 순서예요. 같은 소리만 나오지 않게 그중 하나를 고르는 건 워커예요(예: jobId로)
- 그 검색어 소리가 없으면 빈 배열이에요(오류 아님). 워커는 그 장면을 소리 없이 만들어요
- 오류: 400 `INVALID_REQUEST`(빈 값, 길이 초과, kind·license·query 모양 틀림), 413 `PAYLOAD_TOO_LARGE`
- 앱용 /api는 없어요. 앱은 완성된 쇼츠만 봐요

### 수집 스크립트 (지원 맥에서 한 번)

1. Freesound API로 검색어마다 `license:"Creative Commons 0"`와 길이 조건으로 찾기. 원본 내려받기는 OAuth2가 필요해서 미리 듣기 ogg(고음질)를 받아요
2. `PUT /internal/sounds/{freesoundId}`로 넣기. 맥에서는 SSH 터널로 api /internal에 닿아요

- Freesound API 키는 지원 맥 환경 변수에만 두고 레포에 넣지 않아요
- 스크립트는 lolog-api `scripts/`에 둬요(기본 화자 넣기 스크립트와 같은 자리)
